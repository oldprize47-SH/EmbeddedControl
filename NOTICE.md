# 로컬 통합본의 공개 제한 / Local integration restriction

이 checkout은 원래 공개 embedded 저장소와 비공개 recycling 저장소의 전체 이력을 합친 로컬 준비본입니다. 공개 배포를 승인하거나 원격 가시성을 변경한 것이 아닙니다.

공동 응용 코드, 수업 지원 코드와 공동 문서의 재배포 권리는 미해결입니다. 현재 파일의 개인정보 치환 여부와 별개로, 병합 부모를 통해 비공개 원본 이력 전체가 도달 가능합니다. 이 브랜치, 태그, bundle 또는 Git 이력을 공개 저장소로 전송하지 마세요. 과거 이력의 개인정보 전수 감사도 수행하지 않았습니다.

권장 이관 대상은 기존 비공개 recycling 저장소입니다. 기존 공개 embedded 포크는 그대로 보존하고, 소유자가 대상을 결정한 뒤 통합 커밋을 비공개 저장소에만 이관할 수 있습니다. 이 문서는 push, archive, rename 또는 가시성 변경의 승인이 아닙니다.

This checkout is a local preparation artifact containing both the public embedded history and the full private recycling history. It is not approved for public distribution. Sanitized current files do not sanitize reachable history or grant redistribution rights. Do not send this branch, tags, bundles or history to a public repository. Historical personal data has not been comprehensively audited.

The recommended destination is the existing private recycling repository, with the original public embedded fork preserved. The owner must decide the destination before any remote operation.
