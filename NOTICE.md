# 출처와 이용 안내 / Attribution and use

STM32 수업 실습, RC카와 자동 분리수거함을 한 저장소에서 살펴볼 수 있도록 정리했습니다. 원본 이력과 팀원의 기여를 보존하며, 2026년 9월 29일 저장소 소유자의 공개 요청에 따라 통합본을 공개합니다.

공개 열람은 새로운 오픈소스 라이선스 부여를 의미하지 않습니다. 원본 수업 자료, 공동 코드와 지원 라이브러리의 기존 출처 및 권리를 유지합니다. [분리수거함 출처](projects/recycling/ATTRIBUTION.md) · [상세 안내](projects/recycling/NOTICE.md)

This repository brings together STM32 coursework, an RC car and an automatic recycling system. Original history and team contributions are preserved. The owner requested publication of the integrated portfolio on 29 September 2026.

Public availability does not grant a new open-source license. Existing attribution and rights for coursework, shared code and support libraries remain in effect. See the component notices linked above.
